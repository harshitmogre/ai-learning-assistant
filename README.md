# AI Learning Assistant

An AI-powered personalized learning assistant that helps students learn from their own study materials using Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs).

## 🚀 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- FastAPI
- Python
- LangChain
- Google Gemini API
- ChromaDB
- MongoDB Atlas

## 🎯 Features (Planned)

- User Authentication
- PDF Upload
- Chat with Documents
- AI Quiz Generator
- AI Notes Generator
- Learning Progress Dashboard

🚧 Currently under development.
